Инструкция по использованию:

  • Настройте параметры ноты с помощью ползунков
  • Нажмите "Добавить ноту" или кликните на холст для размещения ноты
  • Перетащите ноту для изменения её позиции
  • Используйте LFO для добавления модуляции частоте, панораме или громкости
  • Нажмите "Воспроизвести" для прослушивания композиции
